# Respira Vida Home Care
Projeto do Checkpoint 3 de Front-end.
Site de uma empresa de oxigenoterapia e home care, que vende equipamentos como CPAP, BiPAP e concentradores e entrega cilindros de oxigênio.

## Tecnologias
- HTML5
- CSS3 com Flexbox
- Google Fonts (Montserrat)
- FontAwesome
